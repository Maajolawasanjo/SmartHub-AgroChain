# Decision governance

The client has supplied multiple complementary and overlapping product specifications. Before implementation of a commercial action, record: (1) source and version, (2) stated requirement, (3) conflict if present, (4) approved decision, (5) implementation and tests.

Do not commit the source PDFs or private client decision register without explicit permission. This public repository lists only the decision categories that block implementation.

- Resale versus managed procurement contract and seller-of-record obligations
- Stock ownership and quantity ledger behavior after fulfilment
- Exact reservation creation/release/expiry point
- 75%-upfront final balance milestone
- Supplier settlement mechanism, supporting evidence, partial/failure/reversal rules
- Cancellation, refund, dispute and approval authority
- Farm verification versus supply review, both distinct from email and phone contact verification
